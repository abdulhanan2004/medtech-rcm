# MEDTECH Multi-Page Website

## Files
- index.html — main dashboard/home page
- end-to-end-rcm.html — End-to-End RCM
- medical-billing.html — Medical Billing
- coding-support.html — Coding Support
- vob-eligibility.html — VOB & Eligibility
- authorization.html — Authorization
- ar-follow-up.html — A/R Follow-Up
- specialties.html — specialty directory
- styles.css — shared design/animations
- script.js — mobile menu, scroll reveal and demo form

## GitHub Pages
Upload all files into the same repository folder (root), then enable GitHub Pages from Settings > Pages using the main branch and root folder.

## Important
The contact form is currently a front-end demo. It displays a confirmation alert but does not send email yet. Connect it to a form/email service before using it for real leads.
